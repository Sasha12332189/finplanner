# FINPLAN UI v2

- Rebuilt Mini App as a mobile-first, iOS-inspired material/glass interface.
- Added working Plan / Activity / Invest navigation and functional controls.
- Added light, dark and system appearance modes with Telegram theme integration.
- Added Ukrainian, Russian and English UI localization.
- Added device-local time greeting: morning, afternoon, evening and night.
- Added European and major international currency selector.
- Added editable starting account balance and monthly spending limit.
- Added fast transaction entry with category shortcuts for common expenses/income.
- Added transaction deletion, goal progress editing/deletion, watchlist add/remove and investment ledger flows.
- Added search-to-watchlist and search-to-trade shortcuts.
- Added server-side persistence for language, theme and starting balance with SQLite migration for existing databases.
- Added protection against selling more recorded investment units than currently held.
